# Capturas antes | después · revisión de Fable · 6-nov-2026

Rama huérfana, solo capturas: el código está en `web/fable-6nov` (sin merge).

- `web-fable-6nov-antes-despues.pdf`: una hoja por URL tocada (32), antes (main 973047b) a la
  izquierda y después (web/fable-6nov) a la derecha, a la misma escala (0,6 pt por px CSS), con
  el resumen de cambios en la cabecera; portada con el índice y, al final, el primer pantallazo
  en Android de 6, 7, 10 y 14 (la banda «Instalar»).
- `capturas/antes/` y `capturas/despues/`: JPEG de página entera a 390 px (Android, Pixel 7),
  a 488 px de ancho (1,25×), y `*-pantalla1.jpg` (primer pantallazo, 390 × 844).
- `resultados/`: estado HTTP, alto, scroll horizontal y errores de consola de cada captura
  (antes 45 páginas, después 47) y la prueba funcional (formulario, banda, generadores).
- `herramientas/`: los scripts. Web compilada en local con el gem github-pages y servida con
  `python3 -m http.server`; todo lo externo (Plausible, tiendas, Web3Forms) se respondía en el
  navegador: no salió ninguna petición.
